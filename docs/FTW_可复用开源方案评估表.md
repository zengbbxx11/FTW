# FTW 可复用开源方案评估表

评估日期 2026-11-23。目标环境为 FTW 0.4.0（`0e55b14`）、Windows x64 WebView2、React 19.3.1、TypeScript 5.9.3、Vite 8.3.8、Tailwind 4.3.5、Tauri 2.12.7、Rust 和 SQLite/SQLx 0.8.6。本表的版本为调研当天官方发布记录，发布时间按 UTC 日期。npm 体积为注册表的包解包体积，Rust 为 crate 压缩包体积，均未计传递依赖。实际 Vite 压缩产物增量、Windows 体积和运行内存需在对应阶段测量。R0 只读依赖和资料。

## 实施取舍

保留 TanStack Query、原生表单和现有 CSS，先完成 R1。R2 引入动态表单和少数弹层，R3 再接表格、拖动和高级筛选。按 Vite 同条件构建比较初始路由及懒加载 chunk，暂定初始压缩增量 100 KiB 为复审阈值，超出先检查重复依赖、整包导入和首屏懒加载。FTW 自行开发的部分集中在字段及权限规则、过滤 AST 到参数化查询、跨进程变更版本、SMTP 状态机、首次开发去重和可靠备份。
