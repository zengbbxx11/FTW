# 人工与 Agent 双向协同

## 当前协同范围

以 Schema `27` 的源码为准。桌面和 MCP 按同一套 Core 规则读写持久化数据。工作台按业务域刷新已打开页面，MCP 后续查询可直接读取已提交的结果。当前 Windows 用户的本地 MCP 客户端无需登记或令牌，统一使用“本机 Agent”身份；自动发信由用户单独保存授权。下方按版本记录的历史实现和验证保留当时的状态。

| 业务 | 双向协同 | 边界 |
| --- | --- | --- |
| 发现与候选调查 | 查询已有客户、候选和开发历史，保存来源及证据，读写待审核候选。 | 外部线索由宿主获准的数据源提供。候选转正沿用查重、状态和版本检查。重复线索和已有人工结论受保护。 |
| 客户建档与管理 | 完整建档、公司联系人、查询、增量更新、归档、查重合并、批量状态和 CSV。 | 身份、版本和授权由 Core 校验。待确认信息交桌面核对，保护已有的人工确认值。 |
| 自定义字段与视图 | 读写共享字段值，管理授权的定义及视图，使用保存条件查询，调整已共享项目顺序。 | 私有字段、默认视图和个人布局由桌面管理。Agent 新建字段默认为共享可写。 |
| 跟进、样品和证据 | 新增和编辑业务跟进，查询样品批次与时间线，追加调查证据及授权核验。 | 核验保留操作主体。由系统生成的收发活动供两端查询。 |
| 草稿、发送和收件 | 共享草稿及历史、按授权发送、查询队列状态、同步来信、读取和回复原会话。 | 持续发送授权与逐封批准由工作台设置。归属有歧义、未知发送结果和拒发名单写入交桌面处理。 |
| 文件与附件 | 按客户编号导入、按文件 ID 读取与下载，读取获准邮件附件并使用已授权发件素材。 | PDF 可另存和发送。Agent 通过独立的素材授权访问可发附件。 |
| 任务、报告和审计 | 两端可查询有记录的业务结果、字段历史、质量问题及邮件分析。 | MCP 可查询不同 Agent 的任务和业务审计。外部 Agent 的执行控制由宿主管理。 |

账户凭据、发送权限调整、业务库备份恢复及本地诊断导出在桌面或便携诊断脚本处理。[操作流程与工具](../MCP_MAIL.md) · [验收与未验证范围](../ACCEPTANCE_TESTS.md#已记录的验证)

| 开发批次 | 查询批次和发送状态 | 提交任务标识、查询单次发送 | 共用发送记录 | 缺少 MCP 批次查询 |

实施顺序为复用现有客户端登记建立按客户端分配的协作权限，补齐共享视图、跟进和草稿编辑、文件和批次入口，再验证隔离数据上的双向读写和拒绝路径。

## 第 24 版协作补全

- 自定义字段保存、创建默认值和合并复制产生类型化的前后值记录。桌面按客户查看全部字段及来源，MCP 按当前字段访问权限读取。
- 客户文档可分段上传至 10 MiB，按编号续传和核对哈希。支持桌面预览 PNG、JPEG 与 WebP。MCP 可分段读取入站和出站邮件附件。
- Agent 可查看待确认回复和候选、提交关联建议。工作台保留人工确认及已有结果校验，拒发名单可通过已授权的 MCP 查询。
- Agent 可查询自己的业务请求和发信批次。桌面和 MCP 复用取消尚未提交邮件及为明确失败准备新草稿的 Core 操作。任务结果保存成败、是否需人工核对及可否在读取最新版本后重新发起。

## 共享排序与故障诊断

- Agent 使用现有字段和视图管理权限调整可编辑项目顺序。单次交换在 Core 事务中校验版本、更新位置并保留登记身份审计。私有、只读及默认项目沿用各自的访问规则。
- 系统状态可导出脱敏 JSON，Core、桌面与 MCP 记录限长且轮转的诊断事件。便携目录带无窗口诊断命令，缺少 Core 时也可生成最小报告。使用第 25 版现有数据结构。
