# FTW 功能与 UI 实施盘点

2026-11-26 · 当前源码版本 `1.1.5`，数据库 Schema `26`。根据现有代码、隔离 Windows 10 桌面截图和阶段验证记录维护。正式便携发布与整机验收仍待执行。[协同验证](HUMAN_AGENT_PARITY.md#当前协同范围) · [发布验收用例](../ACCEPTANCE_TESTS.md)

## 核心能力

| 能力 | 状态 | 可核对的范围 |
| --- | --- | --- |
| Agent 自动代发邮件 | 已实现，模拟传输和 MCP 已验证 | 用户持续授权与可选逐封审批均可使用。Core 校验发件账户、Agent、用途、限额、节流、拒发、首次开发重复、幂等和并发。SMTP 接受、失败、结果未知、退信和人工回复分别记录。真实邮箱联调待验证。 |
| 客户记录管理 | 已实现并有桌面证据 | 联系人表格与看板、详细资料、字段类型、自定义视图、跟进、附件、邮件往来、查重合并和安全恢复。支持跨页选择和按筛选结果批量修改阶段、等级与样品状态。 |
| Agent 辅助维护客户 | 已实现并有桌面及 MCP 证据 | MCP 支持查询、完整建档、增量修改、共享字段和视图、沟通与样品、维护候选与正式客户证据。联系方式及产品兴趣可提交带来源的更正建议，Core 在人工采纳时复核当前值。 |
