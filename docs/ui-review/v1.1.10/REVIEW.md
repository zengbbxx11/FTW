# 1.1.10 客户表格窗口适配

2026-11-27。修复 1.1.9 表格按列宽总和定宽、全屏右侧留下空白的问题。

## 实现

表格使用可用面板宽度，最小宽度仍为各列保存宽度的总和。弹性空余区域承接剩余空间，快捷操作固定在面板右边。窗口变窄或详情并排时，数据区横向滚动，不把余量分摊到手动设置的数据列，也不修改视图定义。

主要修改为 `CustomerTable.tsx` 的表格宽度及弹性列、`customer-workspace.css` 的填充样式。没有数据库迁移、业务规则或 MCP 接口改动。

## 实际核对

复用独立测试数据目录中的三个虚构客户，没有操作日常客户或配置测试邮箱。

- [1002 × 742 窄窗口](narrow.png)：表格内部横向滚动，右侧三个按钮可见。
- [1920 × 1040 最大化窗口](maximized.png)：表头和行背景延伸到面板右边，操作栏位于最右侧。
- [详情并排](detail.png)：数据区缩窄后仍能横向滚动，快捷操作与详情区没有重叠。
- 拖动姓名列宽由 159 → 219 px，界面立即变化，数据库回读保存值为 219；打开详情没有改变此列宽。
- `cargo check --workspace --all-targets --locked`、Core／MCP／更新器 release build、Tauri release build（包含 TypeScript 与 Vite）和 ESLint、`git diff --check` 均通过。Vite 主包约 904 kB，仍有超过 500 kB 的体积提示。

本次是布局修复核对，未执行全量业务回归、模型客户端、真实邮件、不同 DPI 或 Win10 验收。
