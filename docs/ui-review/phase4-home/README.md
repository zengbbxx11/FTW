旧工作台展示两个待办与一张活动列表。本轮加入四张统计卡、双栏活动与邮件进展、趋势、Agent 审计摘要和快捷操作。首轮桌面截图中，邮件进展卡被左侧活动列表撑高。复验版把右栏的进展、审计摘要和快捷操作独立堆叠，收紧图标与文字密度。全局搜索和布局编辑为新增界面。

## 实现与验证范围

- **工作台。** Core 从同一读取事务汇总未归档客户、SMTP 已接受记录、CRM 回复状态、待处理事项与 Agent 审计。环形图以已发客户为分母。趋势按本地日期列出 SMTP 已接受数量，提供可切换的数据表。待审核、回复匹配和业务动态有对应记录入口。
- **布局。** 卡片可显示隐藏、通过上下按钮排序、调整密度和默认时间范围，并可恢复默认。本地 WebView 偏好保存后可重新读取，工作台保留现有启动页设置。
- **全局搜索。** 侧栏或 `Ctrl+K` 打开。Core 生成四类全库计数和每页 20 条结果，关键词可以跨记录字段匹配。文本预览只显示已存储的业务内容，邮件附件打开其原邮件。文件搜索覆盖文件名和关联信息。
- **组件与接口。** 复用已有面板、分页、Tooltip、Radix 控件、Lucide 图标和 TanStack Query。组件来源见[开源组件来源](../THIRD_PARTY.md)。桌面 IPC 新增 `data.search`、`crm.get_activity`，在 `mail.file_workspace` 增加可选的 `document_id` 精确定位。检索和统计使用现有 SQLite 结构。

## 桌面与核心回归

- 隔离桌面样本核对了 8 个有效客户、27 封 SMTP 接受记录和 14 天趋势合计。待审核和近期活动都能打开原记录。布局保存后重新加载 WebView，卡片顺序、可见性、密度及 7 天默认范围均保留，恢复默认布局也已验证。
- 实测 `Ctrl+K` 聚焦搜索，打开客户、原来信、跟进、文件和关联附件邮件。22 条匹配邮件可翻页打开第 22 条草稿，并核对无结果状态。两种视口均完成真机截图复验。
- `npm run lint`、`npm run build`、Tauri 构建、28 项 Rust 测试、2 项前端变更刷新测试和两版 MCP stdio 回归通过。Vite 保留约 696 kB 的主包提示。真实邮箱、Win11、Windows 125% 与 150% 缩放未在本批复验。

预览入口为 `.ftw-dev/ui-phase4-home-preview/workbench.exe`。旁边保留 Core、MCP 和隔离 `data` 目录。
