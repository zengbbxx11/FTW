## 核心回归

- 候选列表每页 20 条，实测可通过关键字找到首屏之外的第 22 个调查样本。切换审核状态、打开并排详情与尽调、确认转正均通过。
- 队列统计与记录分类通过。实测全部提交记录包含四条已入队或已结束的样本记录，草稿会留在草稿分类。选中结果未知项后显示其发送编号和中断原因。
- 同邮箱的两位候选均可在待确认来信中查看。人工关联后，来信退出待确认列表。实际执行查重合并后，SQLite 检查确认原跟进与该来信均转到保留客户，另一条已归档并保留 `merged_into` 关联。
- `npm run lint`、`npm run build`、`cargo fmt --all -- --check` 及 Rust 工作区构建通过。Rust 测试 25 项、前端变更通知测试 2 项通过。MCP `2025-06-18` 和 `2025-11-25` 的工具发现、调用、审批隔离检查通过。Vite 仍提示主包大小约 647 kB，gzip 约 189 kB。
- `D:\FTW\.ftw-dev\ui-phase3-preview\workbench.exe` 已验证可启动隔离 Core。预览目录内的 Core、MCP 和样本数据需一同保留。

样品独立跟踪、多邮箱与签名页专项改造、邮件模板、客户文件和 Agent 变更页进入后续批次。证据目前按候选记录管理，来源网址逐条核验与独立证据状态待扩展。队列提供现有 Core 支持的操作，未知结果保留人工核对提示。
