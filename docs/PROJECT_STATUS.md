# 当前项目状态

更新日期：2026-11-27。当前源码版本为 **1.1.10**，SQLite Schema 为 **28**，MCP 提供 **104 个业务工具**。公开下载版本以 [GitHub Releases](https://github.com/zengbbxx11/FTW/releases) 为准。1.1.10 已完成构建及隔离桌面窗口适配核对，生成 ZIP、更新清单和签名；经一致性备份后使用更新器安装到本地固定体验目录，四个程序及随包说明哈希、数据数量和保留文件均已核对一致。

## 已提供的能力

- 人工与本机 MCP Agent 共用 Rust Core、SQLite、客户、字段与视图、跟进、样品、文件和邮件记录。当前 Windows 用户无需登记令牌；工作台可暂停接入。持续发信仍由用户在工作台授权账户、用途和限额。
- CRM 支持联系人、公司关系、查重合并、CSV、数据质量与精简客户开发概况。统计卡片按 Core 全库规则筛选；工作台“已发且有回复客户”进入对应客户范围。
- 视图可从当前设置或空白创建，配置组合筛选、排序、显示字段、列顺序、密度及表格／看板布局，并显示条件摘要和后端匹配数量。自建视图可删除；默认视图先更换默认项，内置视图可隐藏、归档和恢复。删除视图不删除客户。
- 下拉框统一使用 Radix Select，长列表通过 Popover / cmdk 搜索；输入焦点使用单圈边框。客户表格支持实时拖宽、双击适配本页、列菜单、直接新增属性，以及右侧固定的编辑／跟进／邮件按钮。列宽、顺序、显示状态和密度单独自动保存到当前视图，筛选和排序仍需主动保存。
- 客户表格铺满可用面板，剩余空间由弹性区域承接，不自动拉大已设置的数据列宽；窗口变窄时在表格内部横向滚动。
- 邮件支持 SMTP、IMAP、草稿、回复、模板、多账户、附件和发送队列。Core 保留授权、拒发、配额、节流、首次开发查重、快照、幂等与并发保护；SMTP 结果未知不盲目重发。
- 收件箱保留全部来信；普通未关联邮件不再全部计入客户提醒。有客户邮箱线索或关联建议的业务来信进入“客户来信待核对”。自动回复及投递报告不作为人工回复。
- 人工和 Agent 可按明确选择的邮件标记非客户或恢复，不屏蔽后续来信。分类受处理版本校验和审计保护，重复同步保留标记。待核对界面可搜索已有客户或使用现有表单新建后关联。
- FTW 运行时默认每 10 分钟自动同步已配置邮箱，可调整或关闭；关闭桌面后停止界面定时同步，手动与 MCP 同步保留。
- 客户文件及邮件附件支持下载、发送和逐项管理。PDF 可下载和发送。已有来源资料保留，工作流不要求额外创建调查证据。
- 使用指南按当前路径生成 WorkBuddy 配置；便携更新验证 GitHub Release 清单签名和 ZIP 哈希后原位置安装。诊断报告包含版本、错误和任务关联摘要，不包含邮箱凭据或邮件正文。

## 本轮验证与边界

- 1.1.10 已核对全屏、窄窗口及详情并排布局，列宽拖动与持久化仍有效；构建和静态检查通过。[实际截图及边界](ui-review/v1.1.10/REVIEW.md)。
- 1.1.10 安装前等待 Core 正常退出并建立一致性备份；安装后 Schema 仍为 28，客户、活动、邮箱、草稿、已发、收件与客户文件数量保持一致，保留的非数据库文件哈希与备份一致。此项为安装核对，未追加全量业务回归。
- 已执行 Rust workspace 全目标编译检查、TypeScript、ESLint、Vite 与 Windows 发布构建；发布构建通过；主前端包约 904 kB，仍有超过 500 kB 的体积提示。
- 1.1.9 在独立数据目录中做了桌面控件核对：下拉选择后保存、搜索选项和 Enter、实时拖宽、双击适配、列布局持久化、新字段显示及三个行操作入口。数据库回读确认临时关键词未随列宽保存，其他视图布局未被更改。[截图与边界](ui-review/v1.1.9/REVIEW.md)。
- 1.1.8 已补充视图删除、统计与查询一致、邮件分类恢复等隔离回归用例；本轮未运行整套功能回归、模型客户端测试或最终验收。1.1.9 没有新增迁移，Schema 保持 28；本轮不改变邮件授权和发送规则。
- 1.1.9 固定目录升级前已建立一致性备份，安装后客户、活动、邮箱、草稿、已发、收件、客户文件数量与升级前一致，Schema 保持 28；保留的非数据库文件与备份逐项哈希一致。此项属于安装核对，不代表业务全量回归。
