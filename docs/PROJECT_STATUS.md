# 当前项目状态

更新日期：2026-11-27。当前程序版本为 **1.1.7**，SQLite Schema 为 **27**，MCP 提供 **102 个业务工具**。本页描述当前实现和验证边界；各阶段截图、任务书和旧版测试记录保留其历史含义。

## 已提供的能力

- 人工和本机 MCP Agent 共享 Rust Core、SQLite、客户档案、字段与视图、跟进、样品、文件和邮件记录。当前 Windows 用户的本地客户端无需登记令牌，使用“本机 Agent”身份；用户可以暂停接入，自动发送仍需工作台保存账户、用途和限额。
- CRM 支持联系人资料、公司关系、筛选、查重合并、CSV、沟通、样品和数据质量。客户开发概况向桌面和 MCP 共用返回精简资料、最近活动、邮件状态及相关联系人。
- 邮件支持 SMTP、IMAP、草稿、会话回复、队列、异常、模板、多账户和签名。Core 继续执行授权、拒发、配额、限速、首次开发去重、快照、幂等及并发保护；结果未知不自动盲目重发。
- FTW 运行时默认每 10 分钟同步已配置收件邮箱，可调整或关闭，显示新关联的客户回复及同步结果。关闭 FTW 后界面定时器停止；手动和 MCP 同步入口继续可用。
- 客户详情集中展示最近发信、回复和同步状态。同公司、同域名联系人是开发参考，不禁止正常的同公司多联系人业务。
- 邮件附件可逐个添加、移除和引用客户文件。Agent 仅能使用已授权素材，PDF 可下载和发送。已有来源与证据功能保留，当前工作流不要求额外建立来源证据。
- 快速使用指南按当前路径生成可复制的 WorkBuddy 配置，不自动改写客户端文件。便携更新从本项目 GitHub Releases 获取正式版，验证签名和 ZIP 校验值后更新原位置。旧版使用随包的 `FTW-Update.exe` 过渡。
- 本地诊断记录版本、错误码和任务关联摘要，不包含邮箱凭据或邮件正文；备份恢复、审计和字段冲突核对继续保留。

## 尚未验证

按本轮安排，未重新运行完整自动化测试、Codex 客户端测试或最终逐页视觉验收。连接配置复制按钮的修复后交互、GitHub 下载至安装的完整更新链路、异常恢复、跨设备和不同 Windows 缩放仍待复验。

当前环境的 PowerShell 因 CET 启动异常未能运行官方打包入口；本次便携包使用 Cargo／Tauri、系统压缩工具和同一签名程序生成。PowerShell 打包脚本已更新，其入口仍待在可正常启动 PowerShell 的环境复验。

历史模拟 SMTP／IMAP、MCP 和桌面测试记录不能等同于 1.1.7 全部回归通过。用户此前旧版真实发信成功也不代表本版已完成真实收发回归；本轮未向真实客户发送测试邮件。正式发行说明必须保留这些验证边界。
