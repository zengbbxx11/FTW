# 变更记录

## 0.4.0 · IMAP、Agent 工作流与数据管理

- 增加 IMAP 加密连接、增量收件、UID 去重、邮件会话、待关联、人工修正和客户跟进同步。
- 补齐 MCP 客户、候选、跟进、待审、会话及收件同步工具。变更类请求记录来源，支持请求 ID 防重。
- 增加账户发送上限与纯文本签名，提交 SMTP 前检查账户最近 24 小时的尝试次数。
- 增加工作台概览、客户 CSV 预览导入与导出、业务审计、SQLite 一致性备份与恢复。
- 增加 Windows x64 本地便携 ZIP 构建脚本和 SHA-256 校验值。

## 0.3.0 · SMTP 与 Agent 代发

- 调整主窗口和客户侧栏的滚动条，侧栏独立滚动，关闭和保存按钮保持可见。
- 增加 TLS/STARTTLS 发件账户、Windows DPAPI 凭据、邮件草稿和附件、人工快照审批及持久化发件队列。
- 增加 Codex、WorkBuddy 共用的 MCP stdio 邮件工具，Core 复核审批、收件地址、拒发规则和幂等条件。
- 参考 AppFlowy 联系人库与跟进记录，增加重点客户、样品客户、阶段看板、详情侧栏和跟进补充字段。

## 0.2.0 · M1 · 客户管理

- 增加联系人新增、编辑、详情、搜索、筛选、排序、分页、归档和恢复，以及多渠道与自由文本产品兴趣。
- 增加候选客户证据记录、重复提示、否决、重新审核和事务化转正。
- 增加客户与全局跟进列表、跟进编辑、联系时间推导、Core 写入审计及升级前 SQLite 一致性备份。

## 0.1.0 · M0

- 增加可独立运行的 Windows x64 Rust Core、桌面健康检查和真实 SQLite 初始迁移。
- 以受当前账户 ACL 保护的本机命名管道连接工作台和 Core，支持单一数据目录锁、启动重用和空闲退出。
- 支持便携数据根目录、开发数据隔离、Core 日志、开发脚本和验证脚本。
