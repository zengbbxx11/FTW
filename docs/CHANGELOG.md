# 变更记录

## 1.1.10 · 客户表格窗口适配

- 修复全屏下表格右侧未铺满面板的问题：数据列保留用户列宽，剩余宽度由弹性区域承接，快捷操作固定在面板右侧。
- 窄窗口和详情并排时继续在表格内部横向滚动；不将窗口尺寸或剩余宽度写入保存视图。
- Schema 28、MCP 104 个工具保持不变，未调整业务数据或邮件规则。

## 1.1.9 · 统一下拉框与客户表格操作

- 统一 Radix 选择器与可搜索选项列表，修正输入焦点双层边框；客户、邮件、设置及高级筛选使用同一套控件。
- 表格列宽实时拖动，双击适应本页内容，列菜单可重命名、排序、隐藏和移动，表头提供添加属性入口。
- 每视图自动保存列宽、顺序、显示状态和密度，沿用修订检查；临时筛选和排序仍需主动保存。
- 每行直接显示编辑、跟进、邮件，操作栏固定右侧。Schema 仍为 28，MCP 仍为 104 个业务工具，无新增业务接口或数据库迁移。
- 本轮仅构建、静态检查与隔离控件核对，未执行全量验收、模型客户端或真实邮件测试。

## 1.1.8 · 客户筛选、视图管理与来信处理

- 修复工作台已回复客户入口，客户四张统计卡片支持 Core 全库筛选。
- 视图编辑补充筛选、排序、列布局与匹配数量，自建视图可删除，保留默认及内置视图保护。
- 收件箱区分普通未关联、客户待核对和非客户邮件，支持批量标记及恢复、从发件人新建客户后关联。
- Schema 28 新增非客户处理标记、处理修订及视图删除通知。MCP 新增 delete_customer_view、classify_inbox_messages，共 104 个工具；精简模式暂缓。
- 已补充回归用例；本轮按安排仅做构建及静态检查，不运行功能测试、模型测试或最终验收。[验证边界](PROJECT_STATUS.md)

## 1.1.7 · 桌面命令权限修复

- 补齐连接配置、检查更新、下载及安装更新四个命令的 Tauri 声明和能力权限，修正笼统的错误提示。
- 发行包按版本唯一保存，开发构建单独存放，ZIP 内固定使用 FTW-Portable 目录；已发布版本不覆盖。
- 同步日常使用、接口、发行和验收文档。当前 Schema 仍为 27，MCP 为 102 个工具。
- 已完成编译、静态检查、发布构建、本机程序替换及数据保留核对；未重新执行完整回归或在线更新端到端验收。[验证边界](PROJECT_STATUS.md)

## 1.1.6 · 使用指南与业务体验

- 新增快速使用指南及按当前路径复制 WorkBuddy 配置。

## 既有客户开发闭环与双向协同

以下记录前期开发，数据库迁移到 Schema `27`。该阶段源码版本为 `1.1.7`。正式便携版与跨设备验收状态见[验收用例](ACCEPTANCE_TESTS.md#已记录的验证)。

- 当前 Windows 用户的本地 MCP 客户端无需令牌，共享“本机 Agent”身份，可由工作台暂停和恢复。工作台显示最近连接，任务和草稿支持跨 Agent 接续。
- MCP 增加精简工作台摘要、版本化定义、客户列表摘要、批量建档与跟进及邮件状态查询。
- 桌面新增完整的候选调查、公司联系人、样品批次、客户文件、数据质量、全局搜索、工作台统计、邮件分析和任务视图。支持按共享视图批量管理客户。PDF 可另存及随邮件发送。
- Agent 可按客户端权限使用完整客户档案、共享字段和视图、候选证据、跟进与样品、文件上传下载、查重合并、CSV、邮件分析和操作历史。已打开的工作台按 Core 业务域版本刷新。客户字段修改可追溯到人工或 Agent，受版本检查和冲突核对保护。
- 增加收件同步状态查询和同会话回复草稿。桌面与 MCP 共用会话校验和发送队列，保留原邮件引用、SMTP 结果及客户历史。逐封批准与持续授权继续由 Core 执行。
- 系统状态可导出本地诊断 JSON，窗口打不开时可以用便携诊断脚本。Core、桌面与 MCP 保留限长诊断事件供故障排查。
- Schema `15` 至 `26` 增加样品、证据、文档、公司、协作权限、字段历史、候选修订及回复会话数据。升级已有库时先生成一致性备份。[存储与迁移](ARCHITECTURE.md#sqlite-路径和迁移)

## V1.1.5 · 发件账户管理与 Agent 授权

- 发件账户支持编辑 SMTP 配置和删除。删除后保留邮件与草稿历史，并移除当前账户凭据。
- 首次设置 Agent 发信权限时预选可用范围和最高限额，用户在工作台保存后生效。已有权限保持不变。附件授权及拒发名单调整在工作台确认后生效。

## V1.1.4 · 客户表单分区导航修复

- 新增、编辑客户时，左侧导航会展开、定位并高亮对应区块。分区定位随保存栏和提示信息高度调整，编辑弹窗在当前窗口内滚动。
- 新增客户的自定义属性在加载、读取失败或尚无字段时有明确反馈。可在保留表单草稿的情况下打开字段管理。

## V1.1.3 · 邮件归属核对与数据质量

- 收件箱提供待核对归属视图，集中显示邮件、正文预览、同邮箱客户和手动关联入口。
- 新增客户数据质量检查，列出疑似重复、缺少邮箱或地区以及发信异常。可人工对照并合并正式客户，保留归档源、跟进、会话和邮件审批记录。
- 数据与审计可对比 Agent 的客户字段变更。修订冲突及 `review_only` 建议可人工采纳或保留当前值。

## V1.1.2 · 客户管理界面与编辑体验

- 客户姓名用于打开侧览。阶段、等级和样品状态可单击修改，其他可编辑列用双击或 F2，姓名可用 F2。浮层编辑保留表格行高，完整编辑、邮件与详情入口集中在行尾。
- 新增和编辑共用分区表单，完整编辑后回到原客户详情。统一视图标签、统计、列设置和侧览的深蓝青视觉。系统字段与自定义字段继续由 Core 校验。

## V1.1.1 · 客户工作区与多 Agent 发信权限

- 固定深蓝青主题。客户工作区加入真实概览、独立视图标签、紧凑筛选和列设置、当前行高亮及可调整宽度的客户侧览。高级筛选可预览 Core 查询结果。
- 各 Agent 分别登记并领取令牌。自动发信按名单授权，登记与撤销即时生效。开启或扩大自动发送仍需工作台的 Windows 核验。支持取消等待中的核验请求。
- 迁移保留原有身份和已生效的授权，新增登记默认没有自动发信权限。

## V1.1.0 · Windows x64 便携交付

- 同步桌面、Core、MCP 和便携包版本。ZIP 内含三项程序、便携标志与使用说明。

## V1.1 R7 · 外贸目录、图片与大邮件

- 通过 Windows 文件选择器导入 PDF、JPEG、PNG、WebP，最多 4 件、合计 10 MiB。Core 用文件哈希校验发送内容，旧草稿的内嵌附件继续兼容。
- 经用户核验授权后，已登记 Agent 可查询和引用指定附件。文件内容保存在数据目录，SQLite 与 IPC 传递元数据。
- 大邮件同步优先保存邮件头，支持按需下载最多 16 MiB 的完整邮件、分页读取纯文本及另存附件。备份和还原校验数据库引用的本地对象。

## V1.1 R6 · CRM 邮件开发联动

- 根据草稿、发件作业、SMTP 接受记录、IMAP 来信与拒发规则显示开发状态。收件同步未完成时显示回复待同步。
- 开发前可核对同邮箱、同域名、发件历史及拒发状态。持续授权使用经 Windows 核验的工作台设置，默认仍保留人工审批。
- 区分会话来信、自动回复、可核对的退信和待确认关联，保留所有历史邮件。客户视图可按开发状态、最近发信和回复时间筛选。

## V1.1 R5 · Agent 邮件权限与发件底座

- 邮件中心增加 Agent 发信权限页面、人工审批与禁止 Agent 发送模式、Windows 同账户核验、独立 Agent 登记及撤销。
- 自动授权任务使用原有发件队列，同时记录策略修订、Agent 身份、任务 ID、用途、请求 ID 和快照。不使用虚构的逐封批准记录。
- 启用前要求完成 R6 邮件联动。发送前复核授权、拒发、幂等、首次开发、限速与配额，独立发件账本保留结果未知的占位。

## V1.1 R4 · 桌面工作台界面

- 客户资料在宽窗口右侧并排显示，窄窗口使用模态抽屉。细分基本资料、联系渠道、采购需求、沟通时间线和邮件往来。自定义属性可直改，联系渠道可复制。

- 默认迁移保留全部、重点、样品三种客户视图。支持另存、复制、默认、隐藏、排序、归档和恢复。表格与看板沿用相同的查询。
- 客户表格支持列名、列宽、列顺序、可见性、密度、行内编辑和有界批量业务状态修改。变更以记录版本及数据纪元校验。

## V1.1 R2 · 自定义客户字段

## V1.1 R1 · 业务一致性
