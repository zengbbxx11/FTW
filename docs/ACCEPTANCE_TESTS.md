# FTW V1.1.5 验收用例

完整解压最新版 Windows x64 ZIP，双击 `acceptance\Start-FTW-Acceptance.cmd`。在「系统状态」确认 Core 版本为 `1.1.5`、数据库版本为 `14`，数据目录指向 `acceptance\workspace\data`。这个目录会保留验收进度，需要从空工作区复验时可另解压一份。根目录 `workbench.exe` 用于日常工作，数据目录为根目录下的 `data`。

先复验空状态和客户表单，再导入随包附带的虚构客户。无需配置邮箱。每项可记录通过、失败或未执行。遇到失败，记下用例编号、窗口尺寸、Windows 缩放比例和截图。

## 客户表单回归

| 用例 | 操作 | 预期结果 |
| --- | --- | --- |
| CRM-01 新增表单导航 | 打开「客户 → 新增客户」，依次点左侧的基本信息、联系方式、业务状态、产品兴趣、自定义属性、备注与需求，再回到基本信息。 | 左侧和正文高亮同步。业务状态、产品兴趣、自定义属性、备注与需求自动展开，可看到对应标题和可填写内容。「保存客户」保持可见。 |
| CRM-02 重开已折叠分区 | 点左侧「业务状态」。点正文标题将其折叠，再点左侧同一项。按同样方式复验「产品兴趣」和「自定义属性」。 | 即使导航已经选中，点击仍能重新展开相应分区。客户类型、样品进度等控件可见。 |
| CRM-03 空属性与草稿保留 | 用刚解压的空工作区，在新增表单填入姓名 `导航验收客户`，不保存客户。点「自定义属性 → 管理自定义字段 → 新增字段」，保存一个名为 `验收属性` 的文本字段，再点「返回新增客户」。 | 创建前显示「尚未配置自定义字段」。返回后仍在自定义属性区，出现 `验收属性` 输入框。切回基本信息，原先输入的姓名还在。 |
| CRM-04 自定义值与持久化 | 接续 CRM-03，填入 `样本值` 并保存客户。退出并重新打开工作台，搜索 `导航验收客户`，打开详情。 | 能找到该客户。详情里的自定义属性显示 `验收属性` 和 `样本值`。 |
| CRM-05 窄窗编辑 | 将窗口调到约 1000 × 740 像素。用 CRM-04 客户行末的铅笔进入编辑，点「业务状态」，再点「备注与需求」。 | 弹窗底部在窗口范围内。滚动发生在弹窗内部，业务状态和备注字段都可到达，保存按钮保持可见。 |
| CRM-06 编辑返回 | 在 CRM-05 中改一项后点「取消」。先选「继续编辑」确认值仍在，再取消并选择「放弃修改」。 | 返回原客户详情。详情保留保存前的值。 |

## 其他入口复核

| 用例 | 操作 | 预期结果 |
| --- | --- | --- |
| CRM-07 数据质量入口 | 接续 CRM-04，保留该样本客户的邮箱和国家或地区为空，再打开「客户 → 数据质量」筛选这两类。 | 两类结果都能找到该样本客户，点「打开客户资料」后进入正确记录。 |
| MAIL-01 空收件箱 | 在空工作区打开「邮件中心 → 收件箱 → 待核对归属」。 | 有明确的无待核对邮件提示，可以切回「全部来信」。本项只核查页面状态。 |
| AGENT-01 空变更记录 | 在空工作区打开「数据与审计 → Agent 数据变更」，切换「全部变更」和「待核对」。 | 两种视图都有对应的空状态。若已有隔离 MCP 环境，可向样本客户提交带 `review_only: true` 的 `update_customer`，并检查建议出现在「待核对」，采纳之前原字段值保持原样。 |
| CSV-01 导入与快捷视图 | 在验收工作台打开「数据与审计 → 客户 CSV」，选择解压目录中 `acceptance\sample-customers.csv`，先预览，再导入。打开「客户」并切换全部、重点和样品视图。 | 预览显示可导入 4 条，拒绝 0 条。导入后用 `验收样本` 搜索可看到 4 条。重点视图能找到 `验收样本－艾琳` 与 `验收样本－露西亚`，样品视图能找到 `验收样本－本`。 |
| MAIL-02 发件账户管理 | 在验收工作台添加一份用于验证界面的虚构 SMTP 账户，再编辑名称、主机和端口，留空新授权码并保存。然后删除该账户。 | 列表显示修改后的配置。删除后该账户不再出现在发件账户列表。操作无需连接真实邮箱。 |
| AGENT-02 首次权限设置 | 在验收工作台添加虚构 SMTP 账户并登记 Agent，打开「Agent 发信权限」。 | 界面预选持续授权、该账户、Agent、全部用途及最高限额。状态文字在保存前显示实际生效模式，保存后显示设置成功。 |
